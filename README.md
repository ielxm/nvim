# nvim

## Зависимости
Названия пакетов соответствуют таковым в репозиториях Arch Linux.
| Пакет       |                                                                |
| ----------- | -------------------------------------------------------------- |
| ``go``      | для корректной работы LSP-сервера ``gopls``
| ``rust``    | для корректной работы LSP-сервера ``rust_analyzer``
| ``wget``    | зависимость Mason №1
| ``tar``     | зависимость Mason №2
| ``npm``     | зависимость Mason №3
| ``unzip``   | зависимость Mason №4
| ``ripgrep`` | для нечеткого поиска ``telescope.nvim``
| ``luarocks``| зависимость ``lazy.nvim``

## Сочетания клавиш

| Бинд           |                                                             |
| -------------- | ----------------------------------------------------------- |
| ``<leader>bb`` | Открыть список активных буферов (``telescope.nvim``)
| ``<leader>bf`` | Открыть меню find_files (``telescope.nvim``)
| ``<leader>dd`` | Переключить (toggle) ``vim.diagnostic.setloclist()``
| ``<CTRL>n``    | Переключить (toggle) отображение номеров строк
| ``<CTRL>-``    | Вставить (Insert Mode Only) литераторское тире (—)
| ``<CTRL>-2``   | Вставить (Insert Mode Only) кавычки-ёлочки («»)
| ``<CTRL>-3``   | Вставить (Insert Mode Only) тайм-тег (собственный формат)
